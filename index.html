2. printf의 작동 원리

printf 함수는 문자열 포맷(format string)을 받아서, 그 안에 포함된 서식 지정자(format specifiers)를 찾아 해당 인자(argument)를 출력 형식에 맞게 변환하여 화면에 출력하는 함수입니다.

예를 들어:

printf("Hello %s! You scored %d points.\n", name, score);

- %s는 문자열을, %d는 정수를 출력합니다.

함수는 포맷 문자열을 처음부터 끝까지 순회하면서

  • % 기호가 나오면 그 뒤의 문자를 해석해 어떤 자료형인지 판단하고,
  • 해당 자료형에 맞게 전달된 인자 값을 읽어 출력합니다.

3. 인자 해석과 가변 인수 처리

printf는 가변 인자 함수(variadic function)입니다. 즉, 매개변수의 개수가 고정되어 있지 않고 호출 시점에 달라질 수 있습니다.

C언어에서는 가변 인자를 처리하기 위해 <stdarg.h> 헤더 파일에 정의된 매크로를 사용합니다:

  • va_list: 인자 목록을 가리키는 타입
  • va_start(va_list ap, last_fixed_arg): 가변 인자 리스트 시작을 초기화
  • va_arg(va_list ap, type): 가변 인자에서 다음 인자를 읽음
  • va_end(va_list ap): 가변 인자 처리 종료

ft_printf는 포맷 문자열을 순회하면서 서식 지정자를 만나면, va_arg를 이용해 다음 인자를 해당 자료형으로 꺼내와 출력합니다.

4. 각 자료형과 그의 표현

서식 지정자마다 출력하는 자료형이 다릅니다:

  • %c : 문자(char)
  • %s : 문자열(char *)
  • %d 또는 %i: 정수(int)
  • %u : 부호 없는 정수(unsigned int)
  • %x / %X : 16진수 출력 (소문자/대문자)
  • %p : 포인터 주소 출력

ft_printf에서는 이러한 서식 지정자별로 출력하는 함수를 구현해서 포맷에 맞게 값을 변환하고 출력합니다.
